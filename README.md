# CS2-Match-Prediction
Проект по прогнозированию результатов матчей Counter-Strike 2 с использованием методов машинного обучения.

### Задача проекта

Целью проекта является разработка модели машинного обучения для прогнозирования результатов матчей в игре Counter-Strike 2 на основе исторических данных профессиональных турниров.

В рамках проекта выполняется сбор и анализ статистики матчей, предобработка данных, создание информативных признаков и обучение модели Random Forest для предсказания победителя матча. Модель использует данные о командах, рейтингах, винрейтах и других статистических показателях для определения наиболее вероятного исхода встречи.

Основная задача программной части проекта заключается в автоматизации процесса анализа данных и прогнозирования результатов матчей. Код проекта выполняет загрузку датасета, очистку данных, подготовку признаков, разделение выборки на обучающую и тестовую части, обучение модели, получение прогнозов и оценку качества работы модели с использованием метрик Accuracy, Precision, Recall и ROC-AUC.

Результатом работы является обученная модель и возможность обучать модель (меняя параметры), способная прогнозировать победителя матча Counter-Strike 2 на основе имеющейся статистики и демонстрировать эффективность применения методов машинного обучения в области киберспорта.



Этот проект производит анализ табличных данных (Ранжирование/Классификация) с помощью ансамблевых методов (Random Forest)

Математический анализ: 
Математически метрики: TP - верно угаданные победы;
TN - верно угаданные поражения;
FP - ложные победы;
FN - ложные поражения.
Accuracy для бинарной классификации (Победа/Поражение) рассчитывается как: (TP+TN)/(TP+TN+FP+FN)
    Показывает долю правильных прогнозов среди всех прогнозов модели.

Precision = TP/(TP + FP).
    Показывает, насколько можно доверять предсказанным победам.

Recall = TP/(TP + FN)
    Показывает, какую долю реальных побед модель смогла обнаружить.

ROC-AUC оценивает качество ранжирования вероятностей
    Для создания графика использует два показателя TPR и FPR.

    TPR (True Positive Rate)
    Доля найденных побед.
    TPR = TP/(TP + FN)

    FPR (False Positive Rate)
    Доля ложных побед.
    FPR = FP/(FP + TN)

    AUC (Area Under Curve) - площадь под ROC-кривой.

    AUC=(0,1∫) ​TPR(FPR)d(FPR)

Random Forest: 
    Строится 200 деревьев:Каждое дерево выдаёт прогноз:
    yi ∈{0,1}
    Prediction = (1/N) NΣ(i=1)yi

EWMA - Экспоненциальное скользящее среднее. EWMA придаёт больший вес последним матчам и меньший вес старым результатам.
    EWMAt​=αxt​+(1−α)EMAt−1​
    EWMA t — форма команды после текущего матча;
    xt — результат текущего матча;
    α — коэффициент сглаживания;
    EMAt−1 — форма команды до текущего матча.

    Коэффициент сглаживания:
    α = 2/(span+1)

### Мои наблюдения в датасете:
Изучив материал посвященный всем турнирам Tier 1,2,3 сцены я пришёл к следующим выводам.
Наиболее часто в датасете встречаются карты Mirage и Ancient. Некоторые карты представлены значительно реже, например Train, что может ограничивать качество прогнозов для данных карт.<img width="1318" height="760" alt="image" src="https://github.com/user-attachments/assets/c1720877-d212-428e-a75f-400936608659" />

Распределение побед между командами является относительно сбалансированным, что является благоприятным фактором для обучения модели машинного обучения и снижает риск появления смещения в сторону одного из классов.
Анализ статистики игроков показал, что более высокий показатель ADR (Average Damage per Round) связан с большей вероятностью победы команды. Это свидетельствует о том, что нанесённый урон является одним из важных факторов успеха в матче.
<img width="901" height="596" alt="image" src="https://github.com/user-attachments/assets/d6477205-3d1e-48a5-a765-32e9e747df31" />

Игроки победивших команд в среднем демонстрируют более высокий показатель KAST, что указывает на более стабильный вклад в игровые раунды и эффективность командного взаимодействия.
Корреляционный анализ показал наличие положительной связи между количеством убийств (Kills), показателем ADR и разницей убийств и смертей (KDDiff). Это подтверждает, что данные характеристики отражают общую эффективность игрока.

Датасет содержит большое количество матчей, игроков, команд и турниров, что обеспечивает достаточный объём данных для дальнейшего построения и обучения моделей машинного обучения.
