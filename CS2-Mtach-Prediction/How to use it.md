Как запустить всё это?
Версия использованных библиотек
pandas>=2.0.0
numpy>=1.24.0
scikit-learn>=1.2.0
lightgbm>=3.3.5
matplotlib>=3.7.0
seaborn>=0.12.0

Запущено на PyCharm


---------------------------
1. Установить себе dataset из этого же репозитория (вкладка data). Название: cs2_all_tiers_games. Сохранить путь к датасету : <img width="487" height="52" alt="image" src="https://github.com/user-attachments/assets/68a89703-89b0-4b4b-b4d3-15f4b7042b87" />

2. Установить себе файлы .py : Check-list, Launch-prediction, learning
3. Использовать знакомый интерпретатор 
4. Создать новый проект, на нём же открыть эти три файла.
5. В файле learning.py вставить в кавычки путь до датасета, удалив текст: МЕСТО ДЛЯ ДАТАСЕТА (10 строка). Заменить \ на /. Check-list 5 строка также заменитьпуть к датасету на ВАШ
6. На файле learning.py нажать кнопку запустить. Таким образом модель обучится на основе датасета. (На сайте, откуда был взят датасет, можно выбрать конкретно нужную сцену (Тир 1, Тир 2, Тир 3). За основу же взят вариант cs2_all_tiers_games.csv)
7. Запустить Check-list.py. Ввести нужные никнеймы игроков (Напр. sh1ro, karrigan), клавиша Enter. Ввести название команды (Напр. Navi, клавиша Enter, Консоль: Было найдено: NAVI Javelins), клавиша Enter. 
8. Переходим в файл Launch-prediction.py. Строка 60,61: ввести название команды a,b из пункта 7 (Пример Team Spirit, Natus Vincere). 
Строка 62: ввести название карты. 
Строка 65,66 ввести Id игроков этих команд из пункта 7 (Пример team_a [4710, 965,3395, 3397,1003] vs team_b [169, 1834, 1401, 2934, 7201]. 4710 - это donk)
9. Готово! (В примере выйдет: Вероятность победы Team Spirit: 53.60%
Вероятность победы Natus Vincere: 46.40%
